## 概要（132文字以内）

Gemini の会話を、画像も含めて Markdown ファイルに書き出します。非公式の拡張機能で、Google とは関係ありません。

## 説明

```
Gemini の会話を、ボタン1つで Markdown ファイルに書き出す拡張機能です。
書き出したファイルを ChatGPT や Claude に渡して、会話の続きをするために作りました。

■ できること
・開いている Gemini の会話を、Markdown ファイルとして保存
・自分の会話のページでも、共有リンクのページでも使えます（会話を公開する必要はありません）
・長い会話も最初から最後まで書き出します（画面に表示されていない部分も含む）
・画像を原寸で保存（添付した画像、Gemini が生成した画像）。画像がある会話は zip でまとめて保存
・表、コード、数式もそのまま
・Canvas の最終版、Deep Research の調査計画と報告書（出典の一覧つき）
・Google マップの地図と地名のリンク、Gem の名前、Gemini が作った曲の名前

■ 使い方
1. Gemini の会話を開く
2. ツールバーのアイコンを押す
3. 「ファイルに保存」を押す

■ 書き出される形
往復ごとに「## 番号. 質問の1行目」の見出しが付き、質問は引用、回答はその下に続きます。Obsidian などで目次から話題を探せます。

■ プライバシー
処理はすべてブラウザの中だけで行います。会話の中身を開発者や第三者に送ることはありません。ソースコードは GitHub で公開しています。

■ 注意
・非公式の拡張機能です。Google とは関係ありません。Gemini は Google LLC の商標です。
・Gemini 側の仕様変更で動かなくなることがあります。
・添付した PDF・音声・動画の中身は、Gemini 側で取得できないため書き出せません（ファイル名だけを書きます）。

---

Export your Gemini conversations, including images, to Markdown files with one click — so you can continue the conversation in ChatGPT or Claude.

Features:
- Works on your own chat pages and on shared-link pages (no need to make your chat public)
- Exports long conversations from start to finish, including parts not currently shown on screen
- Saves images at full size (your attachments and images generated by Gemini) together with the Markdown file in a zip
- Keeps tables, code and math as-is
- Exports the final version of Canvas documents and Deep Research plans and reports (with a list of sources)
- Keeps Google Maps references, Gem names and generated song titles

Privacy: everything is processed inside your browser. Conversation content is never sent to the developer or any third party. The source code is available on GitHub.

This is an unofficial extension and is not affiliated with or endorsed by Google. Gemini is a trademark of Google LLC.
```

## 単一用途の説明（Single purpose）

```
開いている Gemini の会話を Markdown ファイル（画像がある場合は zip）に書き出して保存すること。
Exporting the currently open Gemini conversation to a Markdown file (or a zip when it contains images).
```

## 権限ごとの理由

| 権限 | 理由 |
|---|---|
| `scripting` | 開いている Gemini のページの中で、ページが会話を表示するのと同じ通信を呼び出し、会話のデータを受け取るため。To run a function in the open Gemini page that requests the conversation data the page itself uses to display the chat. |
| `downloads` | 書き出した Markdown・zip ファイルを、利用者のコンピューターに保存するため。To save the exported Markdown or zip file to the user's computer. |
| ホスト権限 `https://gemini.google.com/*` | 開いているページが Gemini の会話かを判定し、そのページで会話のデータを受け取るため。To detect whether the open page is a Gemini conversation and to receive the conversation data on that page. |
| ホスト権限 `https://lh3.googleusercontent.com/*`、`https://lh3.google.com/*` | 会話に含まれる画像（添付・生成）を原寸で受け取り、ファイルに含めるため。自分の会話の画像は前者から後者に転送される。To download images in the conversation at full size; images in your own chats are redirected from the former to the latter. |

リモートコード：使っていない（No, I am not using remote code）。

## データの扱いの申告（Privacy practices）

- 扱うデータ：「個人的なコミュニケーション」（会話の内容）、「ウェブサイトのコンテンツ」（会話のページの内容、画像）
- 以下をすべて宣言する
  - データを第三者に販売・譲渡しない
  - 単一用途と関係のない目的に使わない
  - 信用力の判定や融資の目的に使わない
- 説明：会話の内容は、利用者がボタンを押したときにブラウザの中で読み込み、Markdown に変換して利用者のコンピューターに保存するためだけに使う。外部には送信せず、拡張機能の中にも保存しない。
