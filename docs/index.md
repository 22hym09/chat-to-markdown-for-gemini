# Chat to Markdown for Gemini

Gemini の会話を、画像も含めて Markdown ファイルに書き出す Chrome 拡張機能です。

A Chrome extension that exports Gemini conversations, including images, to Markdown files.

- [プライバシーポリシー / Privacy Policy](privacy)
- [ソースコード / Source code](https://github.com/22hym09/chat-to-markdown-for-gemini)
